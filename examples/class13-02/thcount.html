thcount

스레드 여럿이 전역 변수 하나를 올립니다. 잠금 없이(none), 뮤텍스로(mutex), 세마포어로(sem) 올린 결과를 기대값과 비교합니다.

준비 중…

/home/student/class13-02에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./thcount none 4 5000000

    잠금 없이 스레드 4개 × 500만 번. count가 기대값 20000000보다 작으면 갱신이 사라진 것이다.

  2. ./thcount mutex 4 500000

    pthread_mutex로 잠그면 항상 정확히 count = 2000000 (기대 2000000).

  3. ./thcount sem 4 500000

    처음 값 1인 세마포어(sem_wait · sem_post)로 잠가도 결과는 정확하다.

이 VM은 CPU가 1개라서 none 모드의 경쟁은 스레드가 count++ 중간에 타이머 인터럽트로 교체될 때만 생깁니다. 반복 횟수를 500만으로 키웠지만 그래도 기대값이 그대로 나올 수 있으니 몇 번 반복해 보세요. mutex · sem은 VM 속도를 고려해 50만 번으로 줄였습니다.

thcount.c 58줄 
/* thcount.c — 스레드 여럿이 전역 변수 하나를 올린다
 *   ./thcount none  [THREADS [N]]   잠금 없이
 *   ./thcount mutex [THREADS [N]]   뮤텍스로 잠그고
 *   ./thcount sem   [THREADS [N]]   세마포어로 잠그고   (기본: 4개 × 1000000번)
 */
#include <pthread.h>
#include <semaphore.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
 
static volatile long count;     /* 전역 변수: 모든 스레드가 같은 것을 본다 */
static pthread_mutex_t lock = PTHREAD_MUTEX_INITIALIZER;
static sem_t sem;
static long n = 1000000;
static char mode;
 
static void *worker(void *arg)
{
    (void)arg;
    for (long i = 0; i < n; i++) {
        if (mode == 'm') {
            pthread_mutex_lock(&lock);      /* 잠근 스레드가 */
            count++;
            pthread_mutex_unlock(&lock);    /* 직접 푼다 */
        } else if (mode == 's') {
            sem_wait(&sem);
            count++;
            sem_post(&sem);
        } else {
            count++;                        /* 읽고 · 더하고 · 쓴다 */
        }
    }
    return NULL;
}
 
int main(int argc, char *argv[])
{
    int nth = argc > 2 ? atoi(argv[2]) : 4;
    if (argc > 3) n = atol(argv[3]);
    if (argc < 2 || (strcmp(argv[1], "none") && strcmp(argv[1], "mutex") &&
                     strcmp(argv[1], "sem")) || nth < 1 || nth > 64) {
        fprintf(stderr, "사용법: %s none|mutex|sem [THREADS [N]]\n", argv[0]);
        return 2;
    }
    mode = argv[1][0];
    sem_init(&sem, 0, 1);       /* 둘째 인자 0: 한 프로세스의 스레드 사이 */
 
    pthread_t t[64];
    for (int i = 0; i < nth; i++)
        pthread_create(&t[i], NULL, worker, NULL);
    for (int i = 0; i < nth; i++)
        pthread_join(t[i], NULL);           /* 스레드가 끝나기를 기다린다 */
 
    printf("%-5s 스레드 %d개 × %ld번 → count = %ld (기대 %ld)\n", argv[1], nth,
           n, count, nth * n);
    return 0;
}
