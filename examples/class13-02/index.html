Linux Lab/13주차 2차시

공유 메모리 · 세마포어 · 스레드 동기화

POSIX 공유 메모리(shm_open · mmap)와 그 위의 경쟁 상태, 세마포어로 만드는 잠금과 생산자–소비자, 스레드의 뮤텍스 · 조건 변수 · 계수 세마포어를 다루는 예제입니다.

  • shmhelloshm_open · ftruncate · mmap(MAP_SHARED)으로 이름 있는 공유 메모리 /w13_hello 에 글을 써 두고, 서로 무관한 다른 프로세스가 같은 이름으로 붙여 읽습니다.
  • shmrace공유 메모리 /w13_counter 의 count를 여러 프로세스가 잠금 없이 올려, 갱신이 사라지는 경쟁 상태를 관찰합니다.
  • semcountshmrace와 같은 공유 카운터를 프로세스 간 세마포어(sem_wait · sem_post)로 잠그고 올립니다. hold · try · value로 잠금이 쥐어진 상태, sem_timedwait의 시간 제한, 잠근 채 죽은 프로세스의 문제를 확인합니다.
  • ringbuf공유 메모리에 놓은 8칸 원형 버퍼와 세마포어 셋(slots · items · mutex)으로 프로세스 사이의 생산자–소비자를 만듭니다. 가득 차면 생산자가, 비면 소비자가 잠듭니다.
  • thcount스레드 여럿이 전역 변수 하나를 올립니다. 잠금 없이(none), 뮤텍스로(mutex), 세마포어로(sem) 올린 결과를 기대값과 비교합니다.
  • thqueue뮤텍스 하나와 조건 변수 둘(not_full · not_empty)로 8칸 버퍼의 생산자–소비자를 스레드로 만듭니다. pthread_cond_wait를 while로 감싸는 이유와 종료 알림(broadcast)을 보여 줍니다.
  • thlimit계수 세마포어(처음 값 K)로 한 번에 K개 스레드만 임계 구역에 들어가게 합니다. 안에 있는 수와 최댓값은 뮤텍스로 지킵니다.
