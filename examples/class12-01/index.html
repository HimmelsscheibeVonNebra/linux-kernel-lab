파이프 (pipe · dup2 · popen · FIFO)

pipe로 만든 익명 파이프의 읽기·쓰기 끝과 EOF, SIGPIPE/EPIPE, 용량을 확인하고, 셸의 CMD1 | CMD2 를 pipe · fork · dup2 · exec로 직접 만들며, popen과 FIFO(이름 있는 파이프)를 써 보는 예제입니다.

  • pipe_basic한 프로세스 안에서 pipe()로 파이프를 만들고 쓰기 끝에 쓴 뒤, 쓰기 끝을 닫고 읽기 끝에서 EOF까지 읽습니다.
  • pipemsg부모가 파이프로 두 줄을 보내고 자식이 읽습니다. 쓰지 않는 끝점 닫기와 EOF의 관계(ok/leak), 읽는 쪽이 없을 때의 SIGPIPE와 EPIPE, 파이프 용량(cap)을 모드별로 확인합니다.
  • pipe2셸의 CMD1 | CMD2 > FILE 을 pipe · fork · dup2 · execvp로 직접 만듭니다. -o FILE은 CMD2의 표준 출력을 파일로 돌리고, -k는 부모가 쓰기 끝을 닫지 않아 EOF가 오지 않는 상황을 재현합니다.
  • pipeio파이프를 쓰는 다른 두 방법을 보여 줍니다. popen은 셸 명령의 출력을 FILE*로 읽고 pclose로 종료 코드를 받으며, recv/send는 mkfifo로 만든 FIFO를 통해 서로 무관한 두 프로세스가 통신합니다.
