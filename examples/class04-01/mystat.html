Linux Lab/4주차 1차시/mystat

mystat

lstat(2)으로 경로의 종류, device, inode, 링크 수, 권한, 소유자, 크기를 출력합니다. 마지막 심볼릭 링크는 따라가지 않습니다.

준비 중…

/home/student/class04-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. rm -rf mystat_lab && mkdir mystat_lab && printf 'hello\n' > mystat_lab/a.txt

    실습용 디렉토리와 6바이트 일반 파일을 준비합니다.

  2. ./mystat mystat_lab/a.txt

    type=regular, links=1, size=6을 확인합니다.

  3. ln mystat_lab/a.txt mystat_lab/hard.txt && ln -s a.txt mystat_lab/soft.txt

    하드 링크와 심볼릭 링크를 하나씩 만듭니다.

  4. ./mystat mystat_lab/hard.txt

    a.txt와 inode가 같고 links=2로 늘었는지 봅니다.

  5. ./mystat mystat_lab/soft.txt

    type=symlink이고 size는 저장된 문자열 'a.txt'의 길이 5입니다.

  6. ./mystat mystat_lab/missing; echo "status=$?"

    없는 경로는 perror 메시지와 종료 상태 1로 실패합니다.

이 수업의 Makefile은 _FILE_OFFSET_BITS=64를 정의하지 않으므로 32비트에서 2GB 이상 파일이나 32비트를 넘는 inode 번호는 EOVERFLOW로 실패할 수 있습니다. tmpfs의 작은 파일에서는 문제가 없습니다.

소스

mystat.c 42줄 
#define _POSIX_C_SOURCE 200809L
#include <inttypes.h>
#include <stdio.h>
#include <sys/stat.h>
 
static const char *file_kind(mode_t mode)
{
    if (S_ISREG(mode)) return "regular";
    if (S_ISDIR(mode)) return "directory";
    if (S_ISLNK(mode)) return "symlink";
    if (S_ISCHR(mode)) return "char-device";
    if (S_ISBLK(mode)) return "block-device";
    if (S_ISFIFO(mode)) return "fifo";
    if (S_ISSOCK(mode)) return "socket";
    return "unknown";
}
 
int main(int argc, char **argv)
{
    if (argc != 2) {
        fprintf(stderr, "usage: %s PATH\n", argv[0]);
        return 2;
    }
    struct stat st;
    if (lstat(argv[1], &st) == -1) {
        perror(argv[1]);
        return 1;
    }
    printf("type=%s\n", file_kind(st.st_mode));
    printf("device=%ju inode=%ju links=%ju\n",
           (uintmax_t)st.st_dev, (uintmax_t)st.st_ino,
           (uintmax_t)st.st_nlink);
    printf("mode=%04jo uid=%ju gid=%ju size=%jd\n",
           (uintmax_t)(st.st_mode & 07777),
           (uintmax_t)st.st_uid, (uintmax_t)st.st_gid,
           (intmax_t)st.st_size);
    if (fflush(stdout) == EOF) {
        perror("stdout");
        return 1;
    }
    return 0;
}
