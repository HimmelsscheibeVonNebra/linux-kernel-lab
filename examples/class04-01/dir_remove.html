dir_remove

rmdir(2)로 빈 디렉토리를 삭제합니다. 내용이 있는 디렉토리는 ENOTEMPTY로 실패하며 재귀 삭제는 하지 않습니다.

준비 중…

/home/student/class04-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. rm -rf rmdir_lab && mkdir rmdir_lab && printf 'keep me\n' > rmdir_lab/keep.txt

    파일이 하나 들어 있는 디렉토리를 준비합니다.

  2. ./dir_remove rmdir_lab; echo "status=$?"

    비어 있지 않으므로 'Directory not empty'로 실패합니다.

  3. cat rmdir_lab/keep.txt

    실패한 뒤에도 안의 파일은 그대로 남아 있습니다.

  4. rm rmdir_lab/keep.txt && ./dir_remove rmdir_lab

    비운 뒤에는 'removed: rmdir_lab'가 출력됩니다.

  5. ./dir_remove rmdir_lab; echo "status=$?"

    이미 지워진 이름은 ENOENT로 실패합니다.

소스

dir_remove.c 23줄 
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <unistd.h>
 
int main(int argc, char **argv)
{
    if (argc != 2) {
        fprintf(stderr, "usage: %s DIRECTORY\n", argv[0]);
        return 2;
    }
 
    /* 빈 디렉토리만 삭제한다. 내부 파일을 재귀적으로 지우지 않는다. */
    if (rmdir(argv[1]) == -1) {
        perror(argv[1]);
        return 1;
    }
 
    if (printf("removed: %s\n", argv[1]) < 0 || fflush(stdout) == EOF) {
        perror("stdout");
        return 1;
    }
    return 0;
}
