dir_create

mkdir(2)로 디렉토리를 하나 만듭니다. 요청 권한 0755에 umask가 적용되며, 이미 있거나 부모가 없으면 실패합니다.

준비 중…

/home/student/class04-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. rm -rf newdir absent

    이전 실행의 흔적을 지웁니다.

  2. ./dir_create newdir

    'created: newdir'가 출력됩니다.

  3. ls -ld newdir

    권한이 0755 & ~umask(보통 drwxr-xr-x)인지 확인합니다.

  4. ./dir_create newdir; echo "status=$?"

    이미 있는 이름은 EEXIST(File exists)로 실패합니다.

  5. ./dir_create absent/child; echo "status=$?"

    부모 디렉토리가 없으면 ENOENT로 실패합니다. 중간 경로를 자동으로 만들지 않습니다.

  6. rmdir newdir

    만든 디렉토리를 정리합니다.

소스

dir_create.c 23줄 
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <sys/stat.h>
 
int main(int argc, char **argv)
{
    if (argc != 2) {
        fprintf(stderr, "usage: %s DIRECTORY\n", argv[0]);
        return 2;
    }
 
    /* 부모 디렉토리는 이미 있어야 한다. 실제 권한에는 umask가 적용된다. */
    if (mkdir(argv[1], 0755) == -1) {
        perror(argv[1]);
        return 1;
    }
 
    if (printf("created: %s\n", argv[1]) < 0 || fflush(stdout) == EOF) {
        perror("stdout");
        return 1;
    }
    return 0;
}
