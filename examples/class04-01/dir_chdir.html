dir_chdir

getcwd(3)로 현재 작업 디렉토리를 출력하고 chdir(2)로 옮긴 뒤 다시 출력합니다. 바뀌는 것은 이 프로세스의 위치뿐입니다.

준비 중…

/home/student/class04-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. mkdir -p chdir_child

    이동할 대상 디렉토리를 준비합니다.

  2. pwd

    셸의 현재 위치를 기억해 둡니다.

  3. ./dir_chdir chdir_child

    before는 셸의 위치, after는 그 아래 chdir_child의 절대 경로입니다.

  4. pwd

    부모 셸의 위치는 그대로입니다. chdir은 호출한 프로세스에만 적용됩니다.

  5. ./dir_chdir missing; echo "status=$?"

    before만 출력된 뒤 ENOENT로 실패합니다(종료 상태 1).

  6. rmdir chdir_child

    실습 디렉토리를 정리합니다.

소스

dir_chdir.c 37줄 
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <unistd.h>
 
int main(int argc, char **argv)
{
    if (argc != 2) {
        fprintf(stderr, "usage: %s DIRECTORY\n", argv[0]);
        return 2;
    }
 
    /* 수업용 버퍼다. 경로가 더 길면 getcwd의 실패를 처리한다. */
    char cwd[4096];
    if (getcwd(cwd, sizeof cwd) == NULL) {
        perror("getcwd before");
        return 1;
    }
    if (printf("before: %s\n", cwd) < 0 || fflush(stdout) == EOF) {
        perror("stdout");
        return 1;
    }
 
    /* 이 프로세스의 위치만 바뀐다. 실행한 부모 셸의 위치는 그대로다. */
    if (chdir(argv[1]) == -1) {
        perror(argv[1]);
        return 1;
    }
    if (getcwd(cwd, sizeof cwd) == NULL) {
        perror("getcwd after");
        return 1;
    }
    if (printf("after: %s\n", cwd) < 0 || fflush(stdout) == EOF) {
        perror("stdout");
        return 1;
    }
    return 0;
}
