Linux Lab/6주차 1차시/arg_show

arg_show

argc와 argv 배열을 출력하고 argv[argc]가 NULL임을 보여 줍니다. argv[0]은 호출 쪽이 정하는 값이라 프로그램 판별에 쓸 수 없음을 확인합니다.

준비 중…

/home/student/class06-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./arg_show one two three

    argc=4, argv[0]~argv[3], 그리고 argv[4]=(nil)을 확인합니다.

  2. ./arg_show 'a b' '' '*.c' *.c | head -8

    따옴표는 셸이 처리합니다. 빈 문자열도 인자 하나이고, 따옴표 없는 *.c는 셸이 파일 이름들로 펼칩니다.

  3. (exec -a fake-name ./arg_show x)

    exec -a로 argv[0]만 fake-name으로 바뀝니다.

  4. ln -sf arg_show other_name && ./other_name x; rm -f other_name

    같은 실행 파일도 다른 이름으로 부르면 argv[0]이 달라집니다.

README의 bash -c 'exec -a ...'는 bash가 없어 ash 서브셸로 대체했습니다. BusyBox ash 버전에 따라 exec -a를 지원하지 않으면 그 단계만 오류가 나며, 심볼릭 링크 단계로 같은 개념을 확인할 수 있습니다.

소스

arg_show.c 21줄 
#include <stdio.h>
 
/* argv는 널 종료 문자열의 포인터 배열이다.
   argv[argc]는 NULL이 보장되므로 개수와 널 두 가지로
   끝을 확인할 수 있다. argv[0]은 관례상 프로그램 이름이지만
   호출 쪽이 무엇이든 넣을 수 있으므로 보증으로 쓰지 않는다. */
int main(int argc, char **argv)
{
    printf("argc=%d\n", argc);
    for (int i = 0; i < argc; i++) {
        printf("argv[%d]=%s\n", i, argv[i]);
    }
    printf("argv[%d]=%p\n", argc, (void *)argv[argc]);
    /* exec -a 등으로 argv[0]을 바꾼 실행과 비교할 때
       문자열 길이도 함께 출력하면 길이 검증의 출발점이 된다. */
    if (fflush(stdout) == EOF) {
        perror("stdout");
        return 1;
    }
    return 0;
}
