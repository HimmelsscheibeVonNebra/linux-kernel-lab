file_create

open(O_WRONLY | O_CREAT | O_EXCL, 0666)으로 빈 파일을 새로 만들고 close한다. 이미 있는 파일이면 실패하며, 실제 권한은 umask에 따라 정해진다.

준비 중…

/home/student/class03-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. rm -f note.txt; ./file_create note.txt; echo "exit=$?"

    새 파일 생성에 성공하면 종료 상태는 0이다.

  2. ls -l note.txt

    크기가 0바이트인 파일도 권한·소유자 등 메타데이터를 가진다.

  3. ./file_create note.txt; echo "exit=$?"

    O_EXCL 때문에 File exists 오류가 나고 종료 상태는 1이다. 기존 파일은 그대로다.

  4. rm -f mask022.txt mask027.txt; (umask 022; ./file_create mask022.txt); (umask 027; ./file_create mask027.txt); ls -l mask022.txt mask027.txt

    0666 & ~umask 결과로 권한이 각각 rw-r--r--(0644), rw-r-----(0640)이 된다.

  5. rm -f traced.txt; strace -e trace=openat,close ./file_create traced.txt

    마지막 openat 호출의 O_CREAT|O_EXCL 플래그와 반환된 fd(보통 3)를 찾는다. 앞부분은 공유 라이브러리 로딩이다.

소스

file_create.c 15줄 
#include <fcntl.h>
#include <stdio.h>
#include <unistd.h>
 
int main(int argc, char *argv[])
{
    if (argc != 2) {
        fprintf(stderr, "Usage: %s FILE\n", argv[0]);
        return 2;
    }
    int fd = open(argv[1], O_WRONLY | O_CREAT | O_EXCL, 0666);
    if (fd == -1) { perror(argv[1]); return 1; }
    if (close(fd) == -1) { perror("close"); return 1; }
    return 0;
}
