waitpid

자식이 3초 자는 동안 부모가 waitpid(WNOHANG)로 1초마다 찔러 보고(0 반환), 자식이 끝나면 종료 코드 3을 회수한다.

준비 중…

/home/student/class10-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./waitpid

    'Parent still wait...'가 3~4번 찍힌 뒤 Child Exit Status : 3

  2. ./waitpid & sleep 1; ps | grep '[w]aitpid'; wait

    기다리는 동안 부모·자식 두 프로세스가 모두 살아 있음을 ps로 확인

각 단계는 약 3초 걸린다. BusyBox ps는 'ps -o pid,ppid,stat,cmd' 형식 대신 기본 출력으로 본다.

소스

waitpid.c 29줄 
#include <sys/types.h>
#include <sys/wait.h>
#include <unistd.h>
#include <stdlib.h>
#include <stdio.h>
 
int main(void) {
    int status;     pid_t pid;
 
    if ((pid = fork()) < 0) { /* fork failed */
        perror("fork"); 
        exit(1);
    }
 
    if (pid == 0) {   /* child process */
        printf("--> Child process\n");
        sleep(3);
        exit(3);
    }
 
    printf("--> Parent process\n");
    while (waitpid(pid, &status, WNOHANG) == 0) {
        printf("Parent still wait...\n");
        sleep(1);
    }
    printf("Child Exit Status : %d\n", WEXITSTATUS(status));
 
    return 0;
}
