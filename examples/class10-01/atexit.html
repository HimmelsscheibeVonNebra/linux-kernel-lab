atexit

atexit로 등록한 정리 함수가 exit 호출 시 등록의 역순으로 실행됨을 보여 준다.

준비 중…

/home/student/class10-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./atexit; echo "exit=$?"

    Cleanup 2가 먼저, Cleanup 1이 나중에 호출된다. exit=0

  2. ./atexit | cat

    파이프에서도 exit가 stdio 버퍼를 비워 두 줄이 모두 나온다

소스

atexit.c 17줄 
#include <stdlib.h>
#include <stdio.h>
 
void cleanup1(void) {
    printf("Cleanup 1 is called.\n");
}
 
void cleanup2(void) {
    printf("Cleanup 2 is called.\n");
}
 
int main(void) {
    atexit(cleanup1);
    atexit(cleanup2);
 
    exit(0);
}
