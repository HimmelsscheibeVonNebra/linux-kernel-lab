Linux Lab/10주차 1차시/execv

execv

execv에 실행 파일 경로(/bin/ls)와 인자 배열을 직접 넘겨 프로세스를 교체한다. PATH 탐색이 없다는 점이 execlp와 다르다.

준비 중…

/home/student/class10-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./execv

    'Before exec function' 다음에 ls -a 결과, 'After'는 없다

  2. ./execv | head -3

    파이프에서는 'Before' 줄이 사라진다

  3. PATH=/nonexistent ./execv | tail -3

    경로를 직접 주므로 PATH가 틀려도 실행된다

/bin/ls가 BusyBox로 가는 링크로 존재한다고 가정한다. 없으면 'execv: No such file or directory'가 나온다.

소스

execv.c 21줄 
#include <unistd.h>
#include <stdlib.h>
#include <stdio.h>
 
int main(void) {
    char *argv[3];
 
    printf("Before exec function\n");
 
    argv[0] = "ls";
    argv[1] = "-a";
    argv[2] = NULL;
    if (execv("/bin/ls", argv) == -1) {
        perror("execv");
        exit(1);
    }
 
    printf("After exec function\n");
 
    return 0;
}
