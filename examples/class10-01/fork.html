fork

fork가 한 번 호출되어 부모(자식 PID 반환)와 자식(0 반환)에서 두 번 반환되는 것을 getpid·getppid 출력으로 확인한다.

실행 순서

  1. ./fork; sleep 1

    부모·자식이 각각 한 줄씩 찍고 'End of fork'가 두 번 나온다

  2. echo $$

    부모의 'My Parent's PID'가 셸의 PID와 같은지 대조

  3. ./fork | cat

    파이프에서도 줄 수가 같은지, 순서가 바뀌는지 관찰

부모가 wait하지 않으므로 부모가 먼저 끝나면 자식의 PPID가 1(init)로 찍히거나 프롬프트 뒤에 자식 출력이 나올 수 있다.

소스

fork.c 26줄 
#include <sys/types.h>
#include <unistd.h>
#include <stdlib.h>
#include <stdio.h>
 
int main(void) {
    pid_t pid;
 
    switch (pid = fork()) {
        case -1 :  /* fork failed */
            perror("fork");
            exit(1);
            break;
        case 0 :   /* child process */
            printf("Child Process - My PID:%d, My Parent's PID:%d\n",
                    (int)getpid(), (int)getppid());
            break;
        default :   /* parent process */
            printf("Parent process - My PID:%d, My Parent's PID:%d, "
                   "My Child's PID:%d\n", (int)getpid(), (int)getppid(), (int)pid);
            break;
    }
    printf("End of fork\n");
 
    return 0;
}
