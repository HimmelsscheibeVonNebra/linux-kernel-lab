execlp

execlp가 PATH에서 ls를 찾아 현재 프로세스를 교체하므로 성공하면 exec 뒤의 코드는 실행되지 않고, 실패할 때만 -1로 돌아옴을 보여 준다.

준비 중…

/home/student/class10-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./execlp

    'Before' 다음에 ls -a 결과가 나오고 'After'는 나오지 않는다

  2. ./execlp | head -3

    파이프(완전 버퍼링)에서는 버퍼에 있던 'Before' 줄이 exec와 함께 사라진다

  3. ./execlp > out.txt; head -3 out.txt; rm -f out.txt

    파일로 보내도 'Before'가 없다

  4. PATH=/nonexistent ./execlp; echo "exit=$?"

    ls를 찾지 못하면 execlp가 -1로 돌아와 perror 후 exit=1

게스트의 ls는 BusyBox 애플릿이라 출력 모양이 GNU ls와 조금 다르다.

소스

execlp.c 16줄 
#include <unistd.h>
#include <stdlib.h>
#include <stdio.h>
 
int main(void) {
    printf("--> Before exec function\n");
 
    if (execlp("ls", "ls", "-a", (char *)NULL) == -1) {
        perror("execlp");
        exit(1);
    }
 
    printf("--> After exec function\n");
 
    return 0;
}
