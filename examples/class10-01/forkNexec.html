forkNexec

fork한 자식에서 execlp로 ls를 실행하는, 셸이 명령을 실행하는 방식(fork + exec)을 보여 준다. 부모는 기다리지 않고 끝난다.

준비 중…

/home/student/class10-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./forkNexec; sleep 1

    부모는 PID만 찍고 끝나고, 자식은 '--> Child Process' 뒤 ls -a로 바뀐다

  2. ./forkNexec | head -4

    파이프에서는 자식의 '--> Child Process' 줄이 exec로 사라진다

  3. strace -f -e trace=process -o st.txt ./forkNexec > /dev/null; sleep 1; cat st.txt; rm -f st.txt

    clone(fork) → 자식의 execve(ls) → 각자의 exit_group 순서를 시스템 호출로 확인

부모가 wait하지 않아 프롬프트가 ls 출력보다 먼저 돌아올 수 있다. i686에서는 fork가 clone 시스템 호출로, 처음의 execve는 32비트 ABI로 기록된다.

소스

forkNexec.c 28줄 
#include <sys/types.h>
#include <unistd.h>
#include <stdlib.h>
#include <stdio.h>
 
int main(void) {
    pid_t pid;
 
    switch (pid = fork()) {
        case -1 :  /* fork failed */
            perror("fork");
            exit(1);
            break;
        case 0 :   /* child process */
            printf("--> Child Process\n");
            if (execlp("ls", "ls", "-a", (char *)NULL) == -1) {
                perror("execlp");
                exit(1);
            }
            exit(0);
            break;
        default :   /* parent process */
            printf("--> Parent process - My PID:%d\n", (int)getpid());
            break;
    }
 
    return 0;
}
