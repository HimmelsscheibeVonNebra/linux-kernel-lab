helloworld

printf로 한 줄을 출력하고 0을 반환하며 끝나는 가장 단순한 프로그램이다. 종료 상태와 표준 출력 리다이렉션(>, >>)을 관찰한다.

준비 중…

/home/student/class02-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./service/helloworld; echo "exit=$?"

    Hello, world!가 한 번 출력되고 종료 상태는 0이다.

  2. ./service/helloworld > hello.txt; ./service/helloworld >> hello.txt; cat hello.txt

    >는 덮어쓰기, >>는 덧붙이기이므로 파일에 두 줄이 남는다.

  3. wc -l hello.txt

    줄 수가 2인지 확인한다.

  4. strace -e trace=write ./service/helloworld

    printf가 결국 write(1, ...) 시스템 콜 한 번으로 이어지는 것을 본다.

  5. cat /proc/1/comm

    PID 1이 systemd가 아니므로 이 VM에서는 서비스 등록 단계를 진행할 수 없다.

이 VM에는 systemd, sudo, gcc가 없어 README의 컴파일·서비스 등록(systemctl, journalctl) 단계는 실행할 수 없고 직접 실행만 가능하다. 실습 1~6의 apt, python3 웹 서버, curl 등도 사용할 수 없다.

소스

service/helloworld.c 9줄 
#include <stdio.h>
 
int main(void)
{
    /* printf로 문자열을 출력하고 \n으로 줄을 바꿉니다. */
    printf("Hello, world!\n");
    /* 한 번 출력한 뒤 정상 종료합니다. 서비스 로그에서 결과를 확인합니다. */
    return 0;
}
