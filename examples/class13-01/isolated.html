isolated

fork 뒤에 자식이 전역 변수와 힙의 값을 고쳐도 부모에게는 보이지 않음을 보여 줍니다. 가상 주소는 같지만 서로 다른 메모리이며, 부모에게 돌아오는 것은 8비트 종료 상태뿐입니다.

준비 중…

/home/student/class13-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./isolated

    자식은 counter=101, *heap=201 이지만 부모는 100, 200 그대로다. 괄호 안의 주소는 양쪽이 같다. 부모가 받은 것은 종료 상태 42뿐이다.

  2. strace -f -e trace=clone,wait4,exit_group ./isolated 2>&1 | tail -8

    clone으로 자식이 생기고, 자식의 exit_group(42)가 부모의 wait4 결과로 전달되는 과정을 확인한다.

소스

isolated.c 33줄 
/* isolated.c — fork 뒤에는 변수를 고쳐도 서로 보이지 않는다 (IPC가 필요한 이유) */
#include <stdio.h>
#include <stdlib.h>
#include <sys/wait.h>
#include <unistd.h>
 
int counter = 100;                      /* 전역 변수 (데이터 영역) */
 
int main(void)
{
    int *heap = malloc(sizeof *heap);   /* 힙 */
    if (heap == NULL) { perror("malloc"); return 1; }
    *heap = 200;
 
    pid_t pid = fork();
    if (pid == -1) { perror("fork"); return 1; }
 
    if (pid == 0) {                     /* 자식: 두 값을 고친다 */
        counter += 1;
        *heap += 1;
        printf("[자식 %d] counter=%d (%p)  *heap=%d (%p)\n", (int)getpid(),
               counter, (void *)&counter, *heap, (void *)heap);
        return 42;                      /* 부모에게 가는 것은 이 8비트뿐 */
    }
 
    int status;
    waitpid(pid, &status, 0);           /* 자식이 고친 뒤에 확인한다 */
    printf("[부모 %d] counter=%d (%p)  *heap=%d (%p)\n", (int)getpid(),
           counter, (void *)&counter, *heap, (void *)heap);
    printf("[부모 %d] 자식에게서 받은 것: 종료 상태 %d\n", (int)getpid(),
           WEXITSTATUS(status));
    return 0;
}
