binary_write

fopen("wb")으로 열어 int 배열 {10, 20, 30}을 fwrite로 헤더 없이 그대로 저장한다.

준비 중…

/home/student/class03-02-text-binary에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./binary_write numbers.bin; echo "exit=$?"

    화면 출력 없이 파일만 만든다. 종료 상태 0.

  2. wc -c < numbers.bin

    3 * sizeof(int) = 12바이트다.

  3. hexdump -C numbers.bin

    0a 00 00 00 / 14 00 00 00 / 1e 00 00 00: 리틀 엔디언 4바이트 정수 세 개다.

  4. cat numbers.bin; echo

    텍스트로 해석하면 알아볼 수 없다. 같은 바이트라도 해석 방식이 다르다.

  5. ./binary_write /dev/full; echo "exit=$?"

    버퍼에 쌓인 데이터는 fclose 때 실제로 쓰이므로 fclose 오류로 실패(상태 1)가 보고된다.

소스

binary_write.c 21줄 
#include <stdio.h>
 
/* Same-environment native int format, exactly three values, no header. */
int main(int argc, char *argv[])
{
    if (argc != 2) {
        fprintf(stderr, "Usage: %s FILE\n", argv[0]);
        return 2;
    }
    FILE *fp = fopen(argv[1], "wb");
    if (!fp) { perror(argv[1]); return 1; }
    const int values[] = {10, 20, 30};
    size_t n = fwrite(values, sizeof values[0], 3, fp);
    int status = 0;
    if (n != 3) {
        fprintf(stderr, "fwrite: wrote %zu of 3 items\n", n);
        status = 1;
    }
    if (fclose(fp) == EOF) { perror("fclose"); status = 1; }
    return status;
}
