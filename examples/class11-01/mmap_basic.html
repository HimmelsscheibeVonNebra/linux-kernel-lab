mmap_basic

파일 없이 정수 하나 크기의 익명 매핑(MAP_PRIVATE | MAP_ANONYMOUS)을 만들고 42를 쓰고 읽은 뒤 munmap으로 해제하는 입문 예제입니다.

준비 중…

/home/student/class11-01에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./mmap_basic

    *p = 42 가 출력된다. mmap이 돌려준 주소를 일반 포인터처럼 쓴다.

  2. strace -e trace=mmap,mmap2,munmap ./mmap_basic 2>&1 | tail -5

    마지막 쪽에서 길이 4의 MAP_PRIVATE|MAP_ANONYMOUS 매핑과 munmap 호출을 찾는다. 그 앞의 mmap2는 동적 로더가 라이브러리를 올리는 호출이다.

32비트(i686)에서는 mmap()이 mmap2 시스템 콜로 나갑니다. 4바이트를 요청해도 실제 매핑은 페이지(4096바이트) 단위입니다.

소스

mmap_basic.c 29줄 
/* mmap_basic.c: 파일 없이 정수 하나를 매핑해 쓰고 읽는 입문 예제 */
#define _GNU_SOURCE             /* Linux에서 MAP_ANONYMOUS 선언 사용 */
#include <stdio.h>
#include <sys/mman.h>
 
int main(void)
{
    size_t len = sizeof(int);    /* 요청 길이. 실제 매핑은 페이지 단위 */
 
    int *p = mmap(NULL, len,     /* 주소는 커널이 선택, 길이는 바이트 */
                  PROT_READ | PROT_WRITE,   /* 읽기와 쓰기 허용 */
                  MAP_PRIVATE | MAP_ANONYMOUS, /* 비공개, 파일 없음 */
                  -1, 0);       /* 익명 매핑: fd는 -1, offset은 0 */
 
    if (p == MAP_FAILED) {       /* 실패는 NULL이 아니라 MAP_FAILED */
        perror("mmap");
        return 1;
    }
 
    /* 익명 매핑은 0으로 시작한다. 일반 포인터처럼 값을 쓴다. */
    *p = 42;
    printf("*p = %d\n", *p);     /* 같은 주소에서 값을 읽는다. */
 
    if (munmap(p, len) == -1) {  /* 매핑 해제. 이후 p로 접근하지 않는다. */
        perror("munmap");
        return 1;
    }
    return 0;
}
