time_attrs

futimens(2)로 atime·mtime을 지정한 값(2024-01-01, 2024-01-02 UTC)으로 바꾸고, fchmod 뒤에도 그 값이 유지되며 ctime만 현재 시각임을 보여 줍니다.

준비 중…

/home/student/class04-02에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. rm -f times.txt

    O_EXCL로 새로 만들므로 기존 파일을 먼저 지웁니다.

  2. ./time_attrs times.txt

    두 줄 모두 atime=1704067200 mtime=1704153600이고 mode만 0600에서 0640으로 바뀝니다.

  3. stat -c 'atime=%X mtime=%Y ctime=%Z' times.txt

    ctime은 지정할 수 없으며 방금 변경한 현재 시각입니다.

  4. date -d @1704153600

    mtime 값을 달력 시각으로 바꿔 봅니다(KST 2024-01-02 09:00).

  5. ls -l times.txt

    ls가 보여 주는 날짜는 mtime(2024년 1월 2일)입니다.

  6. ./time_attrs times.txt; echo "status=$?"

    이미 있는 경로는 'File exists'로 실패합니다(상태 1).

time_t가 32비트이지만 지정한 시각은 2038년 이전이라 문제없습니다.

소스

time_attrs.c 33줄 
#include <fcntl.h>
#include <inttypes.h>
#include <stdio.h>
#include <sys/stat.h>
#include <time.h>
#include <unistd.h>
 
static int show(const char *label, int fd)
{
    struct stat st;
    if (fstat(fd, &st) == -1) { perror("fstat"); return 1; }
    printf("%s mode=%04jo atime=%jd mtime=%jd ctime=%jd\n", label,
           (uintmax_t)(st.st_mode & 07777), (intmax_t)st.st_atime,
           (intmax_t)st.st_mtime, (intmax_t)st.st_ctime);
    return 0;
}
int main(int argc, char **argv)
{
    if (argc != 2) { fprintf(stderr, "usage: %s NEW_PATH\n", argv[0]); return 2; }
    int fd = open(argv[1], O_WRONLY | O_CREAT | O_EXCL, 0600);
    if (fd == -1) { perror(argv[1]); return 1; }
    int result = 1;
    struct timespec ts[2] = {{1704067200, 0}, {1704153600, 0}};
    if (futimens(fd, ts) == -1) { perror("futimens"); goto done; }
    if (show("after_futimens", fd) != 0) goto done;
    if (fchmod(fd, 0640) == -1) { perror("fchmod"); goto done; }
    if (show("after_fchmod", fd) != 0) goto done;
    result = 0;
done:
    if (close(fd) == -1) { perror("close"); result = 1; }
    if (fflush(stdout) == EOF) { perror("stdout"); result = 1; }
    return result;
}
