sparse_demo

새 파일에서 lseek로 1MiB 위치로 이동한 뒤 1바이트를 써서 희소 파일을 만들고, 논리적 크기(st_size)와 할당 블록 수(st_blocks)를 비교합니다.

준비 중…

/home/student/class04-02에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. rm -f sparse.bin

    O_EXCL로 새로 만들므로 기존 파일을 먼저 지웁니다.

  2. ./sparse_demo sparse.bin

    size=1048577인데 blocks(512바이트 단위)는 그보다 훨씬 작습니다.

  3. ls -l sparse.bin

    ls가 보여 주는 크기는 논리적 크기 1048577바이트입니다.

  4. stat -c 'size=%s blocks=%b unit=%B' sparse.bin

    stat 명령으로 같은 값을 교차 확인합니다.

  5. hexdump -C sparse.bin | head -5

    앞부분은 모두 00(구멍)이고 오프셋 0x100000에 'X'(58) 한 바이트가 있습니다.

  6. ./sparse_demo sparse.bin; echo "status=$?"

    이미 있는 경로는 O_EXCL로 실패합니다(상태 1).

_FILE_OFFSET_BITS=64로 빌드되어 32비트에서도 off_t가 64비트입니다. tmpfs는 실제로 쓴 페이지만 할당하므로 blocks는 보통 8(4KiB 한 페이지)이지만 파일시스템마다 다릅니다.

소스

sparse_demo.c 32줄 
#include <errno.h>
#include <fcntl.h>
#include <inttypes.h>
#include <stdio.h>
#include <sys/stat.h>
#include <unistd.h>
 
int main(int argc, char **argv)
{
    if (argc != 2) { fprintf(stderr, "usage: %s NEW_PATH\n", argv[0]); return 2; }
    int fd = open(argv[1], O_WRONLY | O_CREAT | O_EXCL, 0600);
    if (fd == -1) { perror(argv[1]); return 1; }
    int result = 1;
    if (lseek(fd, (off_t)1024 * 1024, SEEK_SET) == (off_t)-1) {
        perror("lseek"); goto done;
    }
    ssize_t n;
    do { n = write(fd, "X", 1); } while (n == -1 && errno == EINTR);
    if (n != 1) {
        if (n == 0) errno = EIO;
        perror("write"); goto done;
    }
    struct stat st;
    if (fstat(fd, &st) == -1) { perror("fstat"); goto done; }
    printf("size=%jd blocks=%jd blksize=%jd\n", (intmax_t)st.st_size,
           (intmax_t)st.st_blocks, (intmax_t)st.st_blksize);
    result = 0;
done:
    if (close(fd) == -1) { perror("close"); result = 1; }
    if (fflush(stdout) == EOF) { perror("stdout"); result = 1; }
    return result;
}
