helloworld

while (1) 안에서 Hello, world!를 출력하고 fflush한 뒤 sleep(2)로 쉬는 무한 반복 프로그램이다. 스스로 끝나지 않으므로 신호로 종료한다.

준비 중…

/home/student/class02-02에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있고, 소스를 고쳐 make나 gcc로 다시 빌드할 수 있습니다 (처음 컴파일할 때 컴파일러를 내려받느라 잠시 걸립니다). 편집기는 vi입니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./helloworld & sleep 5; kill $!; wait $!; echo "exit=$?"

    5초 동안 2초 간격으로 세 번 출력된다. kill(SIGTERM)로 끝냈으므로 종료 상태는 143(128+15)이다.

  2. ./helloworld > hello.log & sleep 3; ps | grep '[h]elloworld'; kill $!

    백그라운드로 실행 중인 프로세스의 PID를 ps로 확인한 뒤 종료한다.

  3. cat hello.log

    fflush 덕분에 파일로 보낸 출력도 바로 기록되어 두 줄이 남아 있다.

  4. ps | grep '[h]elloworld'; echo "남은 프로세스 확인: grep 종료 상태=$?"

    아무 줄도 나오지 않고 상태가 1이면 프로세스가 남아 있지 않은 것이다.

직접 ./helloworld만 실행하면 Ctrl+C를 누를 때까지 끝나지 않는다. 이 VM에는 make, gcc, systemd, sudo가 없어 README의 Makefile 빌드와 서비스 등록·journalctl 단계는 실행할 수 없다.

소스

helloworld.c 14줄 
#include <stdio.h>
#include <unistd.h>
 
int main(void)
{
    /* 1은 항상 참이므로 아래 작업을 계속 반복합니다. */
    while (1) {
        printf("Hello, world!\n");
        /* 서비스 로그에도 출력이 바로 보이도록 합니다. */
        fflush(stdout);
        /* 2초간 기다린 뒤 다음 반복을 실행합니다. */
        sleep(2);
    }
}
