helloworld

count를 1씩 증가시키며 2초마다 count=N을 출력하는 GDB 연습용 반복 프로그램이다. 여기서는 실행 결과와 시스템 콜만 관찰한다.

준비 중…

/home/student/class02-02에서 student 사용자로 시작합니다. 컴파일된 실행 파일과 소스가 이미 들어 있습니다. 새로고침하거나 재부팅하면 처음 상태로 돌아갑니다.

실행 순서

  1. ./gdb/helloworld & sleep 5; kill $!; wait $!; echo "exit=$?"

    count=1, 2, 3이 2초 간격으로 출력된 뒤 SIGTERM으로 종료된다(상태 143).

  2. strace -f -e trace=write timeout 5 ./gdb/helloworld

    반복마다 write(1, "count=N\n", ...)가 한 번씩 호출되는 것을 본다. timeout이 5초 뒤 SIGTERM을 보내 종료시킨다.

  3. ps | grep '[h]elloworld'; echo "남은 프로세스 확인: grep 종료 상태=$?"

    상태가 1이면 남은 프로세스가 없는 것이다.

이 VM에는 gdb가 없어 README의 break/next/print 실습은 할 수 없다. 대신 strace로 반복 동작을 관찰한다.

소스

gdb/helloworld.c 13줄 
#include <stdio.h>
#include <unistd.h>
 
int main(void)
{
    int count = 0; // 반복 횟수 초기화
    while (1) {
        count++; // 이 줄에 중단점 설정
        printf("count=%d\n", count);
        fflush(stdout);
        sleep(2);
    }
}
